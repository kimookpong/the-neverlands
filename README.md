# The Neverlands (เดอะ เนเวอร์แลนด์ส) — สารานุกรมสำหรับผู้อ่าน

เว็บไซต์: https://kimookpong.github.io/the-neverlands/

เว็บไซต์รวบรวมข้อมูลโลกและภูมิหลังสำหรับผู้อ่าน โดยไม่เปิดเผยตัวตนที่ซ่อนอยู่
เหตุการณ์ในอนาคต หรือบทสรุปของเรื่อง เอกสารผู้เขียนฉบับอ่านได้อยู่เฉพาะในเครื่อง
และไม่รวมอยู่ในประวัติของคลังโค้ดสาธารณะหรือไฟล์ที่เผยแพร่แบบเปิด

## ห้องนักเขียนฉบับอ่านอย่างเดียว

หน้า `/the-neverlands/writer/` มีตัวดูองค์ บท ตอน ต้นฉบับ และเอกสารประกอบ
เผยแพร่เฉพาะตัวโปรแกรมกับข้อมูลที่เข้ารหัสไว้ใน `site/writer/vault.json`
ต้องใส่รหัสผ่านเพื่อถอดรหัสในเบราว์เซอร์ ไม่มีส่วนแก้ไข บันทึก หรือนำเข้าข้อมูล
ไม่ส่งรหัสผ่านหรือเนื้อหาที่ถอดรหัสแล้วกลับเซิร์ฟเวอร์ และไม่บันทึกในที่เก็บข้อมูลถาวรของเบราว์เซอร์
ปุ่มล็อกจะซ่อนและนำเนื้อหาออกจากหน้า เมื่อโหลดใหม่ต้องเปิดด้วยรหัสผ่านอีกครั้ง

ข้อมูลเป็นฉบับส่งออก ณ วันที่เผยแพร่ การแก้ในเครื่องไม่เปลี่ยนเว็บทันที ต้องเข้ารหัส
และเผยแพร่ฉบับใหม่ เครื่องมือเตรียมข้อมูลกับต้นฉบับอยู่ในพื้นที่ผู้เขียนที่ไม่รวมในคลังสาธารณะ
ไม่รวมบันทึกส่วนตัวหรือข้อมูลตรวจรหัสผ่านของโปรแกรมในเครื่องในชุดเผยแพร่

ใช้ AES-GCM (เออีเอส จีซีเอ็ม) กับกุญแจที่ได้จาก PBKDF2 (พีบีเคดีเอฟทู)
แยกข้อมูลชุดนี้จากดัชนีค้นหาและแผนผังเว็บไซต์ของวิกิ การปิดการทำดัชนีไม่ใช่การควบคุมสิทธิ์
ผู้ดาวน์โหลดไฟล์เข้ารหัสสามารถลองเดารหัสผ่านได้ รหัสสั้นจึงไม่เหมาะกับข้อมูลที่ต้องปกปิดอย่างจริงจัง

## แหล่งข้อมูลและคำอ่าน

- เนื้อหาบทความอยู่ใน `content/wiki.json`
- เพิ่มคำอ่านไทยของทุกชื่อและคำอังกฤษที่แสดงต่อผู้อ่านใน `content/pronunciations.json`
- ใช้รูปแบบชื่ออังกฤษตามด้วยคำอ่านไทยในวงเล็บ คำอ่านกับคำแปลเป็นคนละข้อมูล
- คำอ่านชื่อที่แต่งขึ้นยังเป็นแบบชั่วคราว ปรับตามระบบภาษาในอนาคตได้
- ระบบเพิ่มคำอ่านในบทความ ชื่อหน้า เมนู ผลค้นหา และข้อความสำหรับเครื่องมือช่วยอ่าน
- แผนที่แสดงชื่ออังกฤษและคำอ่านไทยสองบรรทัด ที่อยู่เว็บและตัวระบุไม่เปลี่ยน
- ห้ามเพิ่มชื่อที่เป็นความลับลงในคลังคำอ่านสาธารณะ
- บทความสำหรับเผยแพร่ต้องมี `visibility` เป็น `public` ส่วน `status` ใช้
  `established`, `accepted`, `working`, `developing`, `in-world`, `proposed` หรือ `legend`
- ตำนานต้องระบุสถานะความจริงแยกจากข้อมูลที่ผู้เขียนยืนยัน เช่น เกาะเป็นข้อเท็จจริง
  ส่วนต้นไม้แห่งชีวิตและต้นกำเนิดศาสตร์มืดยังเป็นเนื้อหาของตำนาน
- ชื่อยังเป็นชื่อชั่วคราว ต้องแยกเรื่องเล่าทางการในโลกออกจากข้อมูลพื้นฐานของโลก
- บทความต้องมี `slug` ที่ไม่ซ้ำ หมวด เนื้อหา และตัวระบุบทความที่เกี่ยวข้องซึ่งมีอยู่จริง
- รายชื่อเก้าอาณาจักร ผังข้อเสนอทั้งเก้า และสถานที่สำคัญ 40 แห่งอยู่ใน `content/atlas.json`
- ชื่อใหม่ Nhalyra (นาลีรา) และ Orranth (ออร์แรนธ์) รวมถึงตำแหน่งและรูปทรงเป็นข้อเสนอ ภายในเกาะปิดยังไม่เปิดเผย
  และไม่มีหมุดต้นไม้ที่อ้างว่าตำนานเป็นข้อเท็จจริง
- ตัวระบุภาพรวมเดิม `seven-kingdoms` ยังคงใช้เพื่อรักษาลิงก์ที่เผยแพร่แล้ว
  หัวข้อและเนื้อหาที่ผู้อ่านเห็นเปลี่ยนเป็นเก้าอาณาจักร
- ระบบสร้างแผนที่จาก `scripts/atlas.py` ให้เก็บรูปทรงและข้อมูลสถานที่ในไฟล์ข้อมูล
- แนวภูมิภาคบนแผนที่เป็นข้อเสนอ ไม่ใช่แนวควบคุมทางทหารสำหรับทุกช่วงเรื่อง
- ระบบอ่านเฉพาะไฟล์ข้อมูลสาธารณะใน `content/` และภาพกับรูปแบบเว็บใน `site/assets/`

## ตัวละคร ตราสัญลักษณ์ และลำดับบท

- ข้อมูลที่เปิดเผยได้อยู่ใน `content/reader-guide.json` แยกจากแฟ้มผู้เขียนทั้งหมด
- ใช้แบบตัวละครมังงะขาวดำ 19 คนใน `site/assets/manga/` และบัญชีภาพใน `content/artwork.json` ภาพแนวคิดชุดเดิมเก็บไว้ใน `site/assets/portraits/`
- หน้ารวมแสดงใบหน้าและจุดจำจากแบบใหม่ ลิงก์แบบเต็มในบทความแสดงเต็มตัวสามมุมและสองสีหน้า รายละเอียดกายภาพยังเป็นข้อเสนอด้านภาพ
- ความสัมพันธ์ที่ยืนยันในช่วงต้นแยกจากความเกี่ยวข้องตามบทบาท ไม่อนุมานความเป็นญาติจากชื่อหรือสังกัด
- ตราดินแดน 9 แบบและร่างตราตระกูลหรือราชสำนัก 2 แบบสร้างจาก `scripts/reader.py` รูปแบบและชื่อราชสกุลที่ยังไม่กำหนดต้องระบุสถานะไว้
- เครื่องหมายเกาะปิดเป็นเพียงสัญลักษณ์อ้างอิง ไม่อ้างว่าเป็นตราที่เกาะใช้จริง อาณาจักรไร้กษัตริย์ไม่มีตราตระกูลกษัตริย์ที่สมมติเพิ่ม
- หน้าองค์และบทแสดงบทนำ สี่องค์ และบทส่งท้ายรวม 41 บท ใช้ชื่อฉบับสำหรับผู้อ่าน ไม่ส่งชื่อและข้อมูลจุดหักมุมจากแผนผู้เขียนลงหน้าเว็บหรือข้อมูลเบื้องหลัง
- ภาพบุคคลและตราทั้งหมดยังเป็นข้อเสนอด้านรูปลักษณ์ ไม่กำหนดอายุ การสืบสาย หรือรายละเอียดการปกครองขึ้นเอง

## เหตุการณ์แฟนตาซี

- ทะเบียนภูมิหลังก่อนเรื่องหลัก 8 เหตุการณ์อยู่ใน `content/events.json` และบทความใน `content/wiki.json`
- หน้ารวมอยู่ที่ `/the-neverlands/wiki/fantasy-events/` และหมวดเหตุการณ์สำคัญ
- แต่ละเหตุการณ์เชื่อมกลับจากตัวละคร อาณาจักร และหัวข้อ พร้อมลิงก์ไปยังสถานที่เดิมบนแผนที่
- เหตุการณ์ทั้งแปดและกรอบความรู้ประกอบได้รับการรับรองจากผู้เขียนแล้ว ใช้สถานะ `accepted` และแยกการรับรองเหตุการณ์จากความจริงของคำกล่าวในโลก ไม่รับรองข่าวลือว่าเป็นกฎเวทมนตร์
- ห้ามส่งจังหวะบทเฉลย ผลลัพธ์อนาคต หรือแผนเหตุการณ์ของผู้เขียนเข้าข้อมูลสาธารณะ
- `scripts/events.py` สร้างทะเบียนและลิงก์จากข้อมูลสาธารณะเท่านั้น

## ภูมิหลังสงครามฉบับ 0.5

- `/the-neverlands/wiki/great-war/` แสดงช่วงสงบและสงครามก่อนเรื่องหลัก ออเรแวนเริ่มสงคราม เอลเดรเวนสวามิภักดิ์และร่วมรุกรานจนรัฐวาเรสเซียล่มสลาย
- เคแลนสูญเสียแม่ในวาเรสเซียเมื่ออายุสามขวบ แล้วเมรอนพาไปเลี้ยงในเอลเดรเวน แยกสถานที่เติบโตจากภูมิหลังที่เขาเชื่อ
- วาเรสเซียยังปรากฏเป็นดินแดนอาณาจักรเดิมในแผนที่ โดยไม่อ้างว่ารัฐเดิมยังดำรงอยู่
- ข้อมูลการพิชิตและผลลัพธ์ช่วงหลังของเรื่องอยู่เฉพาะผู้เขียน ไม่ส่งลงวิกิหรือข้อมูลเบื้องหลัง

## สร้างและตรวจเว็บไซต์

ใช้ Python (ไพธอน) รุ่น 3.9 ขึ้นไป โดยไม่ต้องติดตั้งชุดคำสั่งเพิ่มเติม:

```sh
python3 scripts/build.py
python3 scripts/check.py
node scripts/check_writer_reader.mjs
python3 scripts/serve.py
```

เปิดตัวอย่างได้ที่ http://127.0.0.1:4173/the-neverlands/

เมื่อส่งการเปลี่ยนแปลงไปยังสาขาหลัก ระบบใน `.github/workflows/pages.yml`
จะสร้าง ตรวจสอบ และเผยแพร่ผ่าน GitHub Actions (กิตฮับ แอ็กชันส์)
ไปยัง GitHub Pages (กิตฮับ เพจส์) โดยส่งเฉพาะโฟลเดอร์ `dist/`
ลิงก์ภายในใช้ฐาน `/the-neverlands/` ให้ตรงกับที่อยู่โครงการ

หากต้องการสร้างเว็บที่อยู่ตรงรากของโดเมน ใช้คำสั่งนี้:

```sh
python3 scripts/build.py --base-path /
```

ระบบตรวจลิงก์ จุดอ้างอิงในหน้า ข้อมูลหน้าเว็บ ข้อมูลค้นหา คำอ่านอังกฤษที่แสดงบนหน้า
ป้ายชื่อสองภาษาบนแผนที่ พิกัดสถานที่ และเส้นทางบกก่อนเผยแพร่
เอกสารผู้เขียนอาจมี `.publication-policy.json` สำหรับกฎตรวจเนื้อหาลับเพิ่มเติม
ไฟล์กฎนี้ไม่ถูกส่งขึ้นคลังสาธารณะ บทความใหม่ยังต้องได้รับการตรวจปมเฉลยโดยผู้เขียน
